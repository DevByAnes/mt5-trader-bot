# نسخهٔ آزمایشی Aurum — یک هفته روی Demo

این خروجی برای آزمایش محلی Windows و MT5 است. سودآوری تأیید نشده؛ اجرای سفارش فقط روی Demo امکان دارد. بک‌اند Python و رابط وب ساخته‌شده روی همان سیستم اجرا می‌شوند. اینترنت در اولین نصب برای دریافت وابستگی‌ها لازم است.

## شروع

1. Python و uv باید نصب باشند (`python -m pip install uv`). MT5 را به حساب Demo وصل کنید. فایل ZIP را در یک مسیر قابل نوشتن استخراج کنید.
2. فایل `mql5/Experts/AurumControl.ex5` و پوشهٔ `mql5/Include/Aurum` را در Data Folder همان MT5، مسیرهای `MQL5/Experts` و `MQL5/Include/Aurum` کپی کنید. DLL لازم نیست.
3. `Start.cmd` را اجرا کنید. حساب Demo متصل به‌صورت فقط‌خواندنی شناسایی می‌شود. رمز حساب لازم نیست. کلید ارتباط در Windows Credential Manager می‌ماند. MT5 از قبل باز می‌تواند به named pipe وصل شود.
4. اکسپرت را روی XAUUSD/M15 قرار دهید. ابتدا `SIGNAL_ONLY` را انتخاب کنید. تنظیمات تاریخچه، clock، تقویم و هزینه‌ها را مطابق preset بررسی‌شدهٔ خودتان نگه دارید؛ preset عمومی شامل حدس دربارهٔ هزینه یا ساعت بروکر نیست. اولین استفاده بدون دادهٔ کالیبراسیون معامله نمی‌کند و علت را نشان می‌دهد.
5. آدرس http://127.0.0.1:1420 را باز کنید. هر سه اتصال باید سالم باشند؛ دادهٔ شبیه‌سازی‌شده در این خروجی فعال نمی‌شود. بخش «تست یک‌هفته‌ای» خودکار شروع به ثبت می‌کند.
6. برای معاملهٔ خودکار Demo، در خود MT5 ورودی‌های `Mode=AUTO_EXECUTE`، `ConfirmDemoAutoExecute=true` و مجوز Algo Trading را بررسی کنید. داشبورد نمی‌تواند این مجوز را فعال کند. ریسک و سقف روزانه را پیش از شروع بررسی کنید؛ حداقل RR خالص ۲ است.

## در طول هفته

سیستم، اینترنت، MT5 و پنجرهٔ Start را روشن نگه دارید. Sleep ویندوز را برای این دوره خودتان تنظیم کنید. بازکردن معامله اجباری نیست: فقط ستاپ معتبر با شرایط مجاز سفارش ایجاد می‌کند. ستاپ‌های قابل تحلیل هنگام اسپرد بالا، خبر، خارج سشن یا محدودیت روزانه هم با وضعیت WAIT و علت مسدودی ثبت می‌شوند. این تفکیک، مجوز دورزدن کنترل ریسک نیست.

روزانه اتصال‌ها، دلیل ورود و فضای دیسک را بررسی کنید. پارامترهای استراتژی را وسط تست تغییر ندهید؛ اگر تغییر لازم شد، گزارش قبل از تغییر را دانلود و تست جدید را جدا ارزیابی کنید. حساب را عوض نکنید. حساب کوچک‌تر می‌تواند به علت حداقل لات و بودجهٔ ریسک امکان معامله نداشته باشد؛ لات خودکار برای عبور از این محدودیت افزایش نمی‌یابد.

Ctrl+C در launcher، رابط و Python را متوقف می‌کند؛ MT5 باز می‌ماند. SL/TP و مدیریت پوزیشن مستقل‌اند؛ با الزام heartbeat، ورود جدید پس از قطع Python مسدود می‌شود. Kill Switch ورود جدید را متوقف می‌کند و پوزیشن را خودکار نمی‌بندد.

## پایان و گزارش

در داشبورد «دانلود گزارش کامل JSON» را بزنید. گزارش شامل نمونه‌های دقیقه‌ای equity، دلایل تصمیم، رکوردهای Deal و شکاف‌های مشاهده است. شمارش Deal برابر شمارش معامله نیست؛ افت سرمایه مربوط به کل حساب است و تغییر موجودی/اکسپرت‌های دیگر روی آن اثر دارند. مدت مشاهده با uptime برابر نیست. سود یا نرخ برد از نبود داده ساخته نمی‌شود.

داده‌ها در `backend/.evidence/mvp/*.sqlite` و ژورنال EA در `Terminal/Common/Files/Aurum/<account>-<symbol>-<magic>` باقی می‌مانند. پاک‌کردن پوشهٔ خروجی دادهٔ تست را از بین می‌برد؛ قبل از حذف از آن نسخهٔ پشتیبان بگیرید. فایل‌های intent و position اکسپرت را پاک نکنید.

این بسته نصب‌کنندهٔ مستقل exe نیست؛ رابط ساخته‌شده + EA کامپایل‌شده + محیط Python قابل نصب است. تقویم/clock معتبر و preset خاص بروکر باید همراه اجرای واقعی بررسی شوند. تست یک هفته باید واقعاً سپری شود؛ build موفق جای آن را نمی‌گیرد.
