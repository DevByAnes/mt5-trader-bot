# تست بومی MT5 — ۲۰۲۶-۱۱-۰۲

MT5 و MetaEditor در `C:\Program Files\MetaTrader 5` پیدا شدند. اجرای واقعی، بیلد 6295 را گزارش کرد. کاربر تأیید کرد حساب Demo هنوز متصل نیست؛ تست‌های این مرحله بدون حساب انجام شدند. وضعیت عمومی قبلیِ «کامپایل بومی اجرا نشده» برای این دو اسکریپت با نتایج زیر جایگزین می‌شود؛ گزارش B2 سند تاریخی مرحلهٔ قبلی است.

| بررسی | نتیجهٔ واقعی |
|---|---|
| کامپایل `InputsTest.mq5` | ۰ خطا، ۰ هشدار، EX5 ساخته شد |
| کامپایل `EconomicsTest.mq5` | ۰ خطا، ۰ هشدار، EX5 ساخته شد |
| ۹۴ input پیش‌فرض در اجرای MQL5 | برابر مقادیر پیش‌فرض Python و معتبر طبق Schema v2 |
| JSON خروجی MQL5 | کوتیشن، backslash، newline، tab، کنترل U+0001 و متن فارسی round-trip شدند |
| ورودی Magic=0 | رد شد |
| RR خالص=1.9 | رد شد |
| ریسک=0.55، خارج از step | رد شد |
| ExecutionMode با enum نامعتبر | رد شد |
| ۹ بردار اقتصادی/ورودی نامعتبر | صفر شکست؛ شامل TP با هزینه، RR حداقل ۲، سرریز و خروجی امن حجم/هدف نامعتبر |

کامپایل اولیه یک هشدار `expression is always false` برای مقایسهٔ `int` با مقدار بالاتر از INT_MAX داشت. generator اصلاح شد تا مقایسهٔ ناممکن تولید نکند؛ حد نوع `int` همان سقف را تضمین می‌کند. محاسبهٔ RequiredReward نیز اکنون سرریز عددی را با نتیجهٔ نامعتبر رد می‌کند.

ابزار تکرار: از پوشهٔ `backend`:

```powershell
python -m uv run python -m tools.native_check --installation "C:\Program Files\MetaTrader 5"
```

ابزار از MetaEditor واقعی استفاده می‌کند و وجود EX5 و متن گزارش «۰ خطا، ۰ هشدار» را می‌سنجد؛ exit code به‌تنهایی ملاک نیست. سپس یک کپی portable مستقل و بدون حساب، با AutoTrading و DLL خاموش، برای تست ایجاد می‌کند. تنظیمات، پروفایل‌ها و رمزهای ترمینال کاربر کپی نمی‌شوند. اسکریپت‌ها سفارش نمی‌فرستند. نتیجهٔ JSON خود MQL5 با Python بررسی می‌شود و فایل‌های شواهد در `.evidence/native` باقی می‌مانند. [خلاصهٔ پاک‌سازی‌شده و hash سورس‌ها](evidence/native/mt5-build-6295.json) در مخزن ثبت است.

مرجع اجرا: [کامپایل خط فرمان MetaEditor](https://www.metatrader5.com/en/metaeditor/help/beginning/integration_ide) و [اجرای Script با تنظیمات Startup](https://www.metatrader5.com/en/terminal/help/start_advanced/start).

پس از اصلاحات، هر ۱۶۶ تست Python پاس شدند. lint، بررسی تایپ و drift خروجی‌های تولیدی نیز پاس شدند؛ تغییرات این مرحله کد فرانت را عوض نمی‌کنند.

محدودیت باقی‌مانده: تلاش اتصال فقط‌خواندنی SDK به ترمینال فعلی با خطای timeout `-10005` نتیجه نداد. نوع حساب، نماد بروکر، قیمت زنده و محاسبات وابسته به مشخصات بروکر در این گزارش تأیید نشده‌اند. تست بالا فقط بردارهای مستقل را اثبات می‌کند. EA اصلی هنوز وجود ندارد؛ Strategy Tester با real ticks، مدیریت پوزیشن، اجرای مستقل EA و Dashboard→EA→Ack واقعی همچنان باقی‌اند. برای ادامهٔ این تست‌ها ابتدا اتصال حساب Demo در خود MT5 لازم است؛ رمز نباید در چت ارسال شود.
