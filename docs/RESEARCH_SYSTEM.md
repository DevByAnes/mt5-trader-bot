# Target stack and verified constraints — 2026-11-02

| Area | Selected / source | Constraint and decision |
|---|---|---|
| MT5 | Official release history checked initially; installed runtime later measured as build 6295 | [Release notes](https://www.metatrader5.com/en/releasenotes); local script compilation/execution now verified in [native results](NATIVE_TESTS.fa.md); no Demo account connected |
| MQL5 execution | CTrade/CSymbolInfo/CPositionInfo/CAccountInfo; native preflight and transaction events | [CTrade](https://www.mql5.com/en/docs/standardlibrary/tradeclasses/ctrade), [profit](https://www.mql5.com/en/docs/trading/ordercalcprofit), [margin](https://www.mql5.com/en/docs/trading/ordercalcmargin), [preflight](https://www.mql5.com/en/docs/trading/ordercheck), [transactions](https://www.mql5.com/en/docs/event_handlers/ontradetransaction); netting/hedging, filling and stops/freeze rules must be evaluated at runtime |
| Main bridge | FILE_COMMON, versioned signed bytes, temp/flush/replace | [FileMove](https://www.mql5.com/en/docs/files/filemove), [FileFlush](https://www.mql5.com/en/docs/files/fileflush); atomicity is tested on Python and must be verified in real MT5; not a cross-process database transaction |
| Optional HTTP | WebRequest only as optional telemetry | [Reference](https://www.mql5.com/en/docs/network/webrequest): synchronous, URL allowlist, not available in Strategy Tester; never required by EA risk management |
| Python | Existing 3.14.10 / FastAPI 0.162.0 / Pydantic 2.14.2 / uv 0.13.6 | B1 pinned lock retained; [Python package releases and rationale](../backend/docs/PHASE0.md) |
| MT5 Python adapter | Optional official MetaTrader5 5.0.6231, read access only | [Integration](https://www.mql5.com/en/docs/python_metatrader5), [published wheels](https://pypi.org/project/MetaTrader5/); Windows x64 wheels include CPython 3.14; running terminal/session required; never import its full execution surface into application services |
| Storage / secrets | SQLite WAL on local disk; Keyring 25.7.0 or explicit environment injection | [WAL](https://www.sqlite.org/wal.html), [keyring](https://pypi.org/project/keyring/), [HMAC](https://docs.python.org/3.14/library/hmac.html); no secrets in JS, DB, profiles or logs; backup/checkpoint and runtime SQLite revision checked |
| Offline data / analytics | NumPy 2.5.4, PyArrow 26.0.0, tzdata 2026.6 | [NumPy](https://pypi.org/project/numpy/), [Arrow](https://pypi.org/project/pyarrow/), [ZoneInfo](https://docs.python.org/3/library/zoneinfo.html), [tzdata](https://pypi.org/project/tzdata/); Windows timezone database fallback, deterministic seeds and UTC data; no live execution dependency |
| Desktop | Existing Tauri API/CLI 2.12.4, React 19.3.1, Vite 8.3.5, TS 5.9.3 strict | Keep pinned UI lock, Query server cache and Zustand preferences; [Tauri capabilities](https://v2.tauri.app/security/capabilities/), [sidecar](https://v2.tauri.app/develop/sidecar/), [signed updater](https://v2.tauri.app/plugin/updater/), [Windows prerequisites](https://v2.tauri.app/start/prerequisites/); native Rust/MSVC not found |
| Validation | pytest/Hypothesis/Schemathesis; Vitest/Playwright; native tester later | [OnTester](https://www.mql5.com/en/docs/event_handlers/ontester), [Strategy Tester constraints](https://www.mql5.com/en/docs/runtime/testing), [ONNX](https://www.mql5.com/en/docs/onnx); closed bars, timestamped swing confirmation, prefix determinism and real-tick/demo evidence are separate gates |

Not selected: Python-based trade submission, MT4/MQL4 APIs, Tauri v1, frontend HMAC, wildcard CORS, plaintext secret configuration, remote webpage UI, unsigned updater placeholders or runtime Python model inference required for EA operation. Existing CSS tokens are retained. The user resolved the gross/net RR conflict in favor of cost-adjusted net RR ≥2; defaults are experimental inputs, not evidence of expected returns. Native execution and desktop packaging still require their acceptance gates.
