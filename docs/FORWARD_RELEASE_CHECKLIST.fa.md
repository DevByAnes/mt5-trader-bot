# خروجی آزمایشی یک‌هفته‌ای

محدوده: Windows، حساب Demo، دادهٔ واقعی MT5، اجرای محلی. معیار پذیرش، ثبت صحیح تصمیم‌ها و اجرای کنترل‌شده است؛ سودآوری هنوز اثبات نشده است.

- [x] تحلیل ستاپ مستقل از فیلتر مجوز ورود، با حفظ کنترل ریسک و RR خالص حداقل ۲.
- [x] علت رد؛ مقدار واقعی و حد برای اسپرد/نوسان/RR/آستانهٔ امتیاز در صورت وجود. ثبت پایدار تصمیم‌ها و نمونه‌های حساب پس از restart.
- [x] گزارش تست قابل دانلود؛ حذف H4/strength بدون داده از نمای اصلی و لینک Validation ناتمام از منوی FILE. مسیر سازگار قدیمی باقی است.
- [x] خروجی ساخته‌شدهٔ وب و launcher محلی بدون وابستگی به Vite در زمان اجرا.
- [x] تست Python، فرانت، مرورگر و کامپایل/بردارهای بومی MQL5.
- [x] بستهٔ خروجی، checksum و راهنمای شروع/پایان هفته.
- [ ] مشاهدهٔ واقعی اتصال نسخهٔ جدید به Demo و داشبورد.
- [ ] آزمون یک هفته توسط کاربر؛ گزارش پس از تکمیل دوره بررسی می‌شود.

فیلترها برای زیادکردن تعداد معاملات کورکورانه حذف نمی‌شوند. ستاپ قابل تحلیل حتی در وضعیت مسدود ثبت می‌شود؛ سفارش فقط با عبور از مجوزهای ورود صادر خواهد شد.

## شواهد این خروجی

۱۸۷ تست Python، ۱۳ تست واحد فرانت، ۲۰ تست مرورگر، بررسی قرارداد، lint و mypy ویندوز/لینوکس پاس شدند. تست یکپارچهٔ قبلی و تست جدید رابط **کامپایل‌شده** شامل ورود حافظه‌ای، دریافت دادهٔ FILE امضاشده از peer مصنوعی، دانلود JSON و restart بک‌اند موفق بودند. تست peer، پذیرش اتصال Demo نیست.

MT5 build 6295: کامپایل EA و پنج اسکریپت با صفر خطا/هشدار، ۷۳ بررسی موتور، ۱۲ بررسی ارتباط، ۹ بررسی اقتصادی و ورودی‌های تولیدی پاس. اجرای این تست‌ها سفارش ارسال نمی‌کند.

مانع پذیرش نشست فعلی: SDK ترمینال `(-10005, IPC timeout)` و ابزار دسکتاپ `native pipe unavailable` گزارش می‌کنند؛ اجرای همین باینری جدید روی Demo هنوز مشاهده نشده است. فعال‌بودن معاملهٔ خودکار یا شروع تست یک‌هفته‌ای ادعا نمی‌شود. راه‌اندازی مطابق `FORWARD_WEEK.fa.md` پس از رفع اتصال انجام می‌شود.
