# برنامهٔ اجرایی و چک‌لیست پذیرش Aurum

مرجع درخواست: پرامپت کامل کاربر، دریافت‌شده در ۲۰۲۶-۱۱-۰۲. وضعیت «انجام‌شده» فقط با کد و شواهد تست ثبت می‌شود. مجوز آخر کاربر، ادامهٔ کل سامانه است؛ محدودیت توقف B1 دیگر مانع فازهای بعد نیست. اجرای معامله در Python و فرانت همچنان ممنوع است.

## معماری و ترتیب وابستگی

EA مستقل در MQL5 ← فایل‌های نسخه‌دار و امضاشده در Common ← Python/FastAPI ← داشبورد موجود Tauri/React/TypeScript. تنظیمات از Schema مشترک مشتق می‌شوند. مسیر `src/` و `src-tauri/` موجود حفظ می‌شود؛ انتقال نمایشی به `app/` ارزش فنی ندارد. API v1 برای مصرف‌کنندهٔ فعلی حفظ می‌شود؛ توسعه‌های قرارداد نسخه‌دار و مستند می‌شوند.

## تصمیم‌های جاری

`ASSUMPTION:` Windows و همهٔ اجزا روی یک ماشین. کانال اصلی FILE؛ HTTP_LOCAL اختیاری و برای Tester مبنا نیست. نبود EA/ترمینال، مجوز جعل دادهٔ زنده یا Ack نیست. کلید HMAC و توکن Telegram وارد JS، log، profile یا `.set` نمی‌شوند؛ bearer نشست فقط در حافظهٔ کلاینت HTTP قرار می‌گیرد. تصمیم RR با پاسخ کاربر حل شد؛ LIVE به‌علت باقی‌بودن پیاده‌سازی و پذیرش بومی مسدود است. این چک‌لیست، تحویل کامل اکسپرت یا نسخهٔ قابل‌معامله را ادعا نمی‌کند.
