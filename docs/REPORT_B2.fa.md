# گزارش مرحلهٔ B2 — ۲۰۲۶-۱۱-۰۲

این مرحله زیرساخت واقعی پل Python را اضافه می‌کند. کل سامانه هنوز کامل نیست: EA اصلی، اتصال کامل تنظیمات v2 و بستهٔ بومی دسکتاپ باقی مانده‌اند. فهرست پذیرش در [برنامهٔ اجرایی](IMPLEMENTATION_PLAN.md) است؛ گزارش‌های قبلی B1 دست‌نخورده‌اند.

## تغییرات قابل‌استفاده

- حالت FILE مستقل از Fixture: پیام نسخه‌دار و امضاشده، تشخیص هویت EA، TTL، جلوگیری از replay و نوشتن اتمیک. نبود EA هیچ داده یا Ack ساختگی تولید نمی‌کند.
- SQLite WAL با migration اتمی، outbox، رزرو اتمی نسخه، بازیابی پس از restart، Idempotency و ثبت نتیجهٔ دیررس. timeout نتیجهٔ نامشخص است؛ نسخه آزاد یا موفق اعلام نمی‌شود.
- Audit زنجیره‌شده و append-only، با شناسهٔ نشست محلی و هویت EA؛ تشخیص تغییر و محدودیت مالک فایل مستند است. API فعلی Audit فقط تغییر تنظیمات اعمال‌شده را نمایش می‌دهد؛ فرمان‌ها نیز در دیتابیس ثبت می‌شوند.
- ticket یک‌بارمصرف WebSocket، بدون bearer در URL. برچسب Fixture سرور در داشبورد و اصلاح ویرایش متوالی تنظیمات پس از Ack.
- کاتالوگ اولیهٔ ۹۴ ورودی و خروجی‌های تولیدی Python/TypeScript/MQL5؛ توابع profile و `.set` امن. فرم و CONFIG فعلی همچنان شش ورودی v1 دارند؛ ویرایش کامل v2 هنوز متصل نیست.
- آداپتر محدود فقط‌خواندنی MT5، Parquet و کندل بسته، CSV خبر با UTC و پوشش زمانی صریح، سشن با DST مستقل، متریک‌های مشاهده‌شده، Swing/ATR، Walk-forward و Monte Carlo تکرارپذیر و نتیجهٔ فرضی محافظه‌کارانه. این توابع جای اجرای راهبرد و گزارش Validation کامل را نمی‌گیرند.
- سورس input و ماژول اقتصادی MQL5 مطابق تصمیم کاربر: RR خالص حداقل ۲ و TP با هزینه. این سورس هنوز در MetaEditor کامپایل نشده است.

## شواهد اجراشده

محیط محلی Windows، Node 24.18.0، Python 3.14.10 و SQLite 3.53.1. همهٔ دستورهای زیر در محیط محلی اجرا شده‌اند؛ CI ویندوز/لینوکس به‌روزرسانی شده، ولی نتیجهٔ اجرای راه‌دور در این گزارش ادعا نمی‌شود.

| بررسی | نتیجه |
|---|---|
| `uv run pytest -q` | ۱۶۶ passed؛ warningها خطا محسوب می‌شوند |
| `uv run aurum-lint` | Ruff و guard عدم ارسال سفارش پاس |
| `uv run mypy` | بدون خطا، ۸۲ فایل؛ بررسی `--platform linux` و `--platform win32` نیز پاس |
| `uv run python -m tools.gen_models --check` | خروجی مدل‌ها مطابق Schema |
| `uv run python -m tools.shared_settings --check` | خروجی مشترک MQL5 مطابق Schema |
| `uv run python -m tools.guard_demo` | نمونهٔ ممنوع عمداً رد شد |
| `uv run python -m tools.smoke` | HTTP/WS واقعی با توکن environment و stdin پاس |
| `npm run lint` و `npm run contract:check` | پاس |
| `npm test` | ۹ passed |
| `npm run test:e2e` | ۲۰ passed |
| `npm run test:integration` | دو سناریوی مرورگر/FastAPI واقعی پاس |
| `npm run build` | typecheck و build وب پاس؛ هشدار bundle حدود ۶۰۳ kB باقی است |

تست‌های جدید شامل امضای نامعتبر و بایت تصادفی، پیام منقضی، replay، خرابی replace، قطع EA، restart میان پذیرش و انتشار، Ack دیررس/متعارض، خطای دیسک و بازیابی همان درخواست، عدم گرسنگی Ack معتبر پشت فایل خراب، رقابت دو اتصال برای نسخه، rollback مهاجرت ناموفق، هویت متفاوت حساب، دستکاری Audit، کندل باز، prefix سوئینگ، شکاف داده، ترتیب مبهم SL/TP، خبر فاقد پوشش و DST هستند.

تست مرورگر با MSW خاموش ابتدا دو تنظیم متوالی را از FastAPI در **Fixture** می‌گیرد و Ack/نسخهٔ ۸ و ۹ را بررسی می‌کند. سپس سرور در حالت **FILE بدون EA** اجرا می‌شود؛ EA آفلاین، داده unavailable و فرمان‌ها غیرفعال‌اند. این تست نه EA واقعی است نه Demo. تصاویر: [Fixture](screenshots/integration/python-dashboard.png)، [FILE بدون EA](screenshots/integration/file-no-ea.png).

## موارد باقی‌مانده و کمک لازم

پیاده‌سازی EA مستقل، دو ستاپ، اجرای بومی، مدیریت پوزیشن/ریسک پایدار و مصرف امضاشدهٔ فایل‌ها هنوز باقی است. تأیید دوم سروری برای شل‌کردن ریسک، همهٔ ورودی‌ها در UI، ingest ژورنال، Validation کامل و lifecycle/حفاظت اسرار بومی Tauri نیز باید تکمیل شوند. FILE v1 فعلاً افزایش ریسک و LIVE را رد می‌کند.

ساخت سورس و تست‌های مستقل از ترمینال بدون کمک کاربر ادامه‌پذیر است. برای کامپایل و پذیرش بومی، MetaEditor/MT5، نام دقیق نماد بروکر و حساب Demo با نوع Netting/Hedging لازم خواهد شد؛ رمز لازم نیست. کامپایل MQL5، real-tick Tester، Demo، Forward و build بومی Tauri اجرا نشده‌اند و هیچ‌کدام پاس محسوب نمی‌شوند.
